Estrategia de Hidratación
Componente React	Directiva	Razón
AnimatedSection	client:visible	Solo hidrata cuando entra en viewport
FaqAccordion	client:visible	Solo cuando se ve en pantalla
Carousel	client:idle	Cuando el navegador está idle
VideoBackground	client:load	Necesita cargar video lo antes posible
Pasos de Implementación
 1. Init: npm create astro@latest → minimal
 2. Integrations: npx astro add react + npx astro add tailwind
 3. Dependencies: npm install motion embla-carousel-react
 4. Crear data/content.ts: todo el copy
 5. Crear components/ui/: Button, Container, Heading, Paragraph, SectionLabel, SectionHeader
 6. Crear components/cards/: todas las cards
 7. Crear components/layout/: Section wrapper
 8. Crear components-react/: AnimatedSection, FaqAccordion, Carousel, VideoBackground
 9. Crear layouts/Landing.astro: layout base
10. Crear homepage/sections/: todas las secciones en orden
11. Crear homepage/index.astro: ensamblar secciones
12. Crear pages/index.astro: ruta que renderiza homepage
13. Build: npm run build → verificar
